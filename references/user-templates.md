# 用户输入模板与场景快速模板

本文档供用户快速描述需求时参考，也用于 AI 引导用户补充信息。

---

## 一、用户输入模板

### 基础模板（适合新手）
```
主题：[你想拍什么]
风格：[电影感/网感/广告风/纪录片等]
时长：[4-15秒]
情绪：[温暖/紧张/搞笑/治愈等]
```

### 进阶模板（适合有想法的用户）
```
【视频主题】：一句话描述你想表达的内容
【视觉风格】：电影风格/导演风格/色彩风格
【参考素材】：是否有图片/视频/音频参考
【运镜需求】：推拉摇移/一镜到底/快切等
【声音需求】：对白/旁白/音效/配乐风格
【时长要求】：4-15秒具体秒数
【画面比例】：16:9横屏 / 9:16竖屏 / 2.35:1宽银幕
【负面需求】：不要出现什么元素
```

### 场景快速描述
```
场景：[产品展示/情感短剧/特效大片/舞蹈展示/美食展示...]
主体：[人物/产品/风景/动物...]
动作：[走动/转身/打斗/跳舞/展示...]
环境：[室内/室外/城市/自然/科幻...]
```

## 二、场景快速模板

### 情感短剧模板
```
【类型】：虐心/甜宠/爽剧/搞笑
【角色】：霸总/灰姑娘/闺蜜/情敌
【场景】：雨夜街头/豪华办公室/温馨小屋
【核心冲突】：误会/表白/分手/重逢
【对白】：[关键台词]

时长建议：10-15秒
风格建议：国产短剧风，快剪节奏，高颜值滤镜
画面比例：9:16竖屏（适配抖音/快手）
```

### 产品广告模板
```
【产品】：[产品名称/类型]
【卖点】：[核心卖点1-3个]
【目标受众】：[人群描述]
【调性】：高端/亲民/科技/温暖
【场景】：[使用场景]
【行动号召】：[结尾文案]

时长建议：8-15秒
风格建议：商业广告风，产品特写，高级感
画面比例：9:16竖屏（信息流广告）或 16:9横屏（品牌广告）
```

### 特效大片模板
```
【类型】：武侠/科幻/魔幻/动作
【核心特效】：[特效描述]
【对决双方】：[角色1] VS [角色2]
【招式/技能】：[具体描述]
【场景】：[战斗环境]
【高潮时刻】：[最燃瞬间]

时长建议：10-15秒
风格建议：好莱坞特效，粒子炸裂，慢动作高潮
画面比例：16:9横屏 或 2.35:1宽银幕
```

### 舞蹈/运动模板
```
【类型】：舞蹈/运动/极限运动
【主体】：[人物描述]
【动作】：[核心动作]
【节奏】：[快/中/慢]
【场景】：[环境描述]
【运镜】：跟拍/环绕/第一人称

时长建议：8-12秒
风格建议：动感节奏，卡点剪辑，酷炫运镜
画面比例：9:16竖屏（短视频）或 16:9横屏（MV感）
```

### 美食展示模板
```
【菜品】：[食物名称]
【展示方式】：制作过程/成品展示/吃播
【特写】：[关键细节]
【氛围】：温馨/高级/街头
【声音】：煎炒声/咀嚼声/背景音乐

时长建议：6-10秒
风格建议：美食纪录片，暖色调，微距特写
画面比例：9:16竖屏（短视频）或 16:9横屏（纪录片）
```

### 科普教学模板
```
【主题】：[科普内容]
【呈现方式】：CGI动画/实拍混剪/数据可视化
【视觉风格】：4K写实/卡通风/信息图表
【旁白】：[讲解内容摘要]
【关键画面】：[需要展示的核心场景]

时长建议：10-15秒
风格建议：4K CGI写实，教育感，冷色科技调
画面比例：16:9横屏
```

### Vlog/生活记录模板
```
【主题】：[日常/旅行/探店/运动]
【主体人物】：[人物描述]
【场景流转】：[场景1 → 场景2 → 场景3]
【剪辑风格】：快剪碎片化/沉浸长镜头/卡点切换
【声音】：背景音乐风格/环境音

时长建议：10-15秒
风格建议：手持感，生活化，自然色调
画面比例：9:16竖屏
```

### MV/音乐卡点模板
```
【歌曲风格】：[电子/摇滚/民谣/说唱等]
【画面主题】：[与歌词相关的视觉主题]
【卡点方式】：节拍切镜/动作卡点/光效卡点
【参考音频】：@音频1
【画面风格】：[赛博/复古/日系/韩系]

时长建议：8-15秒
风格建议：MV级画质，音画强同步
画面比例：按平台选择
```

## 三、常见调整指令速查

| 调整类型 | 示例指令 |
|---------|---------|
| 时长 | "延长到15秒" / "缩短到8秒" / "改成10秒" |
| 运镜 | "镜头更动感" / "一镜到底" / "多切镜" / "手持感" |
| 情绪 | "更虐心" / "更燃" / "更治愈" / "更紧张" / "更欢快" |
| 特效 | "特效更炫" / "更写实" / "加入粒子" / "水墨风格" |
| 对白 | "修改台词为..." / "去掉对白" / "保留旁白" |
| 风格 | "更电影感" / "更网感" / "更广告风" / "纪录片风格" |
| 节奏 | "节奏更快" / "更舒缓" / "卡点更准" |
| 融合 | "把 A 和 B 结合" / "用 A 的开头 + C 的结尾" |
| 比例 | "改成竖屏" / "宽银幕" / "方形" |
