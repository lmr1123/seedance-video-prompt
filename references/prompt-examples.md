# Seedance 2.0 提示词示例库

## 一、基础示例

### 1. 纯文本描述（最简单）
```
一只可爱的橘猫在阳光明媚的午后，慵懒地躺在窗台上打盹，阳光透过窗帘洒在它柔软的毛发上，营造出温暖治愈的氛围。10秒。

负面提示：不要出现人物、不要阴暗的色调
```

### 2. 单图片参考
```
@图片1 中的人物转身望向镜头，微笑着挥手，背景是繁华的城市夜景，霓虹灯闪烁。8秒。

负面提示：不要模糊的面部、不要抖动的镜头
```

### 3. 多模态组合
```
以 @视频1 的运镜方式，展现 @图片1 中的场景，配合 @音频1 的氛围感，创造一个充满科幻感的未来都市场景。15秒。

负面提示：不要低质量的特效、不要不连贯的转场
```

### 王家卫风格
```
【王家卫90年代香港文艺片风格】

90年代香港文艺片风格，复古胶片感，高感光度噪点，暧昧的黄绿色调，抽帧效果，忧郁氛围。

[00:00-00:04] 镜头1：隔着玻璃的窥视
一个满是雨水的红色公用电话亭。穿着卡其色风衣的男士，手里紧握着听筒，并没有说话，只是在听。雨水在玻璃上流淌，把他的脸扭曲得像一幅油画。
```

## 四、最强垂直商业化场景示例（爆款必看）

### 电商产品广告（高级香水/美妆）
```
【15秒 · 顶奢香水商业广告】

视觉风格：微距摄影、高级感、流体折射光影、黑金调色。

0-3秒 镜头1：极近特写，缓慢平移
深邃的黑色背景中，一束锐利的顶光打在菱形切割的香水瓶上。玻璃瓶身在缓慢旋转，折射出耀眼的光芒，画面极尽奢华。

4-8秒 镜头2：高速摄影微距，推镜头
香水喷溅的瞬间。使用幻影时间（Phantom Time）超慢动作，细密的水珠像碎钻一样在空中定格、散开，穿过一束琥珀色的光柱。

9-15秒 镜头3：中景，视觉后退留白
光影流转，香水瓶静立在光滑的黑曜石大理石台面上，水波纹倒影轻轻荡漾。画面渐暗，品牌定调。

声音设计：起先是空灵的合成器铺垫，喷洒刹那是清脆清凉的“冰块碰撞声”，随后女声高级吟唱渐起。

负面提示：无文字、无水印、无字幕、不要廉价感、不要粗糙光影
```

## 五、运镜类型示例

### 一镜到底
```
【一镜到底·追踪镜头】

一镜到底，长镜头，跟随运镜，连续不中断。

镜头从街头开始，跟随一位跑步者上楼梯、穿过走廊、进入屋顶，最终俯瞰城市。全程不切镜头，保持流畅的运动感。人物在画面中始终清晰，背景不断变化。镜头与人保持适当距离，既有代入感又能展示环境。

时长：15秒

负面提示：不要跳跃剪辑、不要模糊的过渡
```

### 希区柯克变焦
```
【希区柯克变焦·眩晕效果】

希区柯克变焦，dolly zoom，眩晕感，震惊时刻。

镜头推进的同时变焦拉远，背景拉伸而主体大小保持不变。用于表现人物震惊、恐惧或意识到真相的瞬间。配合紧张的音乐和人物瞳孔放大的特写，营造强烈的不安感。

时长：5秒

负面提示：不要过度使用、不要模糊的主体
```

### 环绕拍摄
```
【360度环绕拍摄】

环绕镜头，orbit shot，全方位展示，戏剧性。

镜头以人物为中心，360度环绕拍摄。人物站在原地，表情变化丰富。背景随着镜头移动展示不同的环境元素。在环绕过程中，光线也在变化，从正面光到侧光再到逆光。配合慢动作效果，营造浪漫或戏剧性的氛围。

时长：8秒

负面提示：不要晃动的镜头、不要不稳定的运动
```

## 六、多模态组合示例

### 图片+视频参考
```
@图片1 为首帧，参考 @视频1 的运镜效果，展示一个人物从静止到奔跑的场景。保持图片中人物的形象一致性，复刻视频中的镜头运动方式。

时长：10秒
风格：电影感，手持摄影

负面提示：不要改变人物长相、不要抖动过度
```

### 音频+情绪引导
```
根据 @音频1 的情绪节奏，生成一个匹配的视频。音乐高潮部分使用快切和特效，低潮部分使用慢镜头和静谧画面。

时长：15秒
风格：MV风格，音乐卡点

负面提示：不要与音乐节奏不符的剪辑
```

### 视频延长
```
将 @视频1 延长5秒。延续当前的场景和情绪，人物继续向前走，镜头跟随，最终消失在画面远处。保持与原视频风格一致。

延长时长：5秒

负面提示：不要风格突变、不要不自然的过渡
```

## 七、负面提示词示例

### 通用负面提示
```
负面提示：模糊、低画质、变形、不自然、抖动过度、曝光过度、曝光不足
```

### 人像负面提示
```
负面提示：面部变形、不自然的表情、多余的手指、模糊的眼睛、不对称的脸
```

### 风格负面提示
```
负面提示：现代感元素（用于古装）、高饱和度（用于冷淡风）、卡通感（用于写实风格）
```

### 技术负面提示
```
负面提示：低分辨率、噪点过多、压缩伪影、水印、logo
```

## 使用建议

1. **根据需求选择模板**：确定视频类型后选择对应的示例
2. **组合使用**：可以结合多个示例的元素
3. **调整时长**：根据实际需求调整时间段分配
4. **添加负面提示**：明确告诉AI不要生成什么
5. **迭代优化**：生成后根据效果持续调整
