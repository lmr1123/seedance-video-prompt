# 风格组合指南

本文档提供同一基础提示词在不同电影风格下的呈现方式，帮助用户快速选择合适的视觉风格。

---

## 基础提示词示例

> **两个漂亮女孩穿着睡衣在宿舍房间嬉笑打闹，阳光从窗户洒进来，照亮整个房间，画面清晰明媚。**

---

## 同一基础提示词 × 15种电影风格

### 1. 郭敬明《小时代》风格

**特点**：高饱和度、奢华感、慢镜头、美颜滤镜拉满

```
时长: 10秒
风格: 郭敬明小时代美学

提示词:
两个精致的女孩身穿丝绸质感的 designer 睡衣——一个是淡香槟金吊带真丝裙，一个是珍珠白蕾丝边睡袍——在装修精致的公寓式宿舍里嬉闹。超大落地窗让清晨的阳光倾泻而入，形成戏剧性的逆光轮廓。镜头以60fps慢动作捕捉她们打闹的瞬间，发丝在空中飘扬，皮肤呈现瓷器般的光泽。房间布置精致奢华，香薰蜡烛、 designer 抱枕、水晶台灯等道具一闪而过。整体色调偏暖金，高对比度，人物轮廓光明显，呈现偶像剧级别的精致美感。

视觉风格:
- 画面质感: 4K超清，轻微柔焦，高级商业广告感
- 色彩风格: 暖金主调，高饱和，橙青分离调色
- 运镜方式: 升格慢动作+环绕+大量特写
- 特效元素: 逆光光晕、镜头光斑、皮肤柔焦美颜

声音设计:
- 配乐: 华丽弦乐+钢琴，戏剧感强
- 音效: 慢动作下的笑声回响

负面提示: 暗调、自然光、生活化、素颜、凌乱背景
```

### 2. 岩井俊二《情书》日系清新风格

**特点**：柔和自然光、低对比度、胶片颗粒、慵懒治愈

```
时长: 10秒
风格: 岩井俊二日系清新

提示词:
慵懒的周末清晨，两束柔和的阳光穿过白色纱帘，在陈旧的木地板上投下淡黄色的光斑。两个女孩穿着简单的棉质睡衣——淡蓝色的吊带背心配短裤、米白色的宽松T恤——坐在有些磨损的地毯上轻声嬉笑。她们的动作不紧不慢，像是刚睡醒的样子，头发自然地散落在肩上。镜头以手持的方式近距离观察她们，偶尔轻微失焦又重新对焦。房间里堆着书本、 CDs、还有一张老旧的书桌。整体画面像是被时光漂洗过，带着淡淡的怀旧感。

视觉风格:
- 画面质感: 16mm/35mm胶片感，明显颗粒，柔和的色彩
- 色彩风格: 低饱和，淡青+暖黄，日系胶片调色
- 运镜方式: 手持跟拍，呼吸感晃动，自然不做作
- 特效元素: 柔焦、胶片颗粒、轻微过曝的高光

声音设计:
- 配乐: 小林武史风格钢琴，极简治愈
- 音效: 窗外的风声、远处的车声、轻柔的笑声

负面提示: 高饱和、锐利画面、精致布置、浓妆、戏剧光效
```

### 3. 陈可辛《那些年》台湾青春片风格

**特点**：阳光灿烂、怀旧色调、自然青春、回忆感

```

风格: 台湾青春校园怀旧

提示词:
2000年代初的大学女生宿舍，阳光从老旧的铝合金窗框斜射进来，在地上画出斜长的光影。两个女孩穿着那个年代常见的睡衣——碎花棉睡裙、印着卡通图案的大T恤——正蹲在地上翻看一本漫画书，时不时笑作一团。她们的头发随意地扎着，脸上带着刚睡醒的红晕。房间里堆满那个年代的物品：台式电脑、磁带、贴满海报的墙壁、晾着的衣服。镜头用暖黄色的怀旧滤镜，偶尔加入胶片闪帧效果，像是翻开一本老相册。

视觉风格:
- 画面质感: 2000年代DV感+胶片颗粒，略带褪色
- 色彩风格: 暖黄怀旧调，略低的饱和度
- 运镜方式: 模拟手持DV，偶尔变焦推拉，有年代感

声音设计:
- 配乐: 九把刀风格青春吉他，回忆感强
- 音效: 老式电风扇嗡嗡声、翻书声、2000年代流行歌从收音机传出

```

### 4. Netflix《性爱自修室》欧美青春剧风格

```

视觉风格:
- 画面质感: 数字高清，锐利，现代感强
- 色彩风格: 大胆鲜艳，高饱和，英式复古配色
- 运镜方式: 快节奏剪辑+手持+大量反应镜头
- 特效元素: 夸张表情特写、羽毛慢动作

- 配乐: 英式独立流行，欢快节奏
```

### 5. 王家卫《花样年华》文艺慢调风格

**特点**：慢镜头、浓烈色彩、情绪化、诗意独白

```
时长: 10秒
风格: 王家卫文艺美学

提示词:
（画外音独白）「有时候，最美好的时光，就是这样无意义地虚度......」

缓慢的镜头里，阳光以不真实的角度穿透半透明的窗帘，在墙上形成一道道金色的条纹。两个女孩穿着复古质感的丝绸睡衣——墨绿色吊带、酒红色丝袍——她们的每一个动作都像是被刻意放慢。一个女孩伸出手，轻轻推了一下另一个的肩膀，对方的头发在慢镜头中缓缓飘起。她们的笑容带着一丝恍惚，仿佛沉浸在自己的世界里。房间里的物件被阳光勾勒出清晰的轮廓——梳妆台上的香水、镜子里模糊的倒影、飘动的窗帘。

视觉风格:
- 画面质感: 浓郁胶片感，高对比，强烈的明暗分离
- 色彩风格: 浓烈的红/绿/金色，强烈的主色调
- 运镜方式: 大量慢动作，固定镜头+缓慢推轨
- 特效元素: 时间流逝感、抽帧效果、情绪化光影

声音设计:
- 配乐: 纳京高爵士乐或大提琴独奏
- 音效: 缓慢的呼吸声、衣料摩擦声、远处的钟声
- 旁白: 可选：文艺独白（如上）

负面提示: 明快节奏、自然光、生活化、现代感
```

### 6. 韦斯·安德森《布达佩斯大饭店》对称美学风格

**特点**：极致对称、糖果色调、复古玩偶感、精致构图

```
时长: 10秒
风格: 韦斯·安德森对称美学

提示词:
一个如同玩偶屋般完美的宿舍房间，所有物品都以极致的对称性排列。画面正中央是一张复古风格的床，两个女孩穿着柔和的糖果色睡衣——一个是淡粉色天鹅绒睡袍，一个是淡蓝色丝绸套装——坐在床的两侧，动作完全对称。阳光从正对镜头的窗户照进来，形成完美平衡的光影。她们同时拿起枕头，同时扔向对方，动作如同精心编排的舞蹈。房间里的每一件物品——书本、台灯、相框——都严格遵循对称构图。

视觉风格:
- 画面质感: 数字高清，无颗粒，如同玩具世界
- 色彩风格: 糖果色调，粉红/粉蓝/淡黄/米白
- 运镜方式: 正面固定机位，极少移动，严格对称构图
- 特效元素: 平面感、戏剧化布光、复古道具

声音设计:
- 配乐: 法式手风琴+古典吉他，俏皮优雅
- 音效: 精确的音效，如同默片

负面提示: 手持晃动、自然光、生活化、不对称构图
```

### 13. 宫崎骏动画风格（真人版）

**特点**：童话感、清新治愈、奇幻元素、温暖明亮

```
时长: 10秒
风格: 宫崎骏童话治愈风

提示词:
```
