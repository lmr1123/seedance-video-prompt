# 风格组合指南

本文档提供同一基础提示词在不同电影风格下的呈现方式，帮助用户快速选择合适的视觉风格。

---

## 基础提示词示例

> **两个漂亮女孩穿着睡衣在宿舍房间嬉笑打闹，阳光从窗户洒进来，照亮整个房间，画面清晰明媚。**

---

## 同一基础提示词 × 5种电影风格

### 1. 郭敬明《小时代》风格

**特点**：高饱和度、奢华感、慢镜头、美颜滤镜拉满

```
时长: 10秒
风格: 郭敬明小时代美学

提示词:
两个精致的女孩身穿丝绸质感的 designer 睡衣——一个是淡香槟金吊带真丝裙，一个是珍珠白蕾丝边睡袍——在装修精致的公寓式宿舍里嬉闹。超大落地窗让清晨的阳光倾泻而入，形成戏剧性的逆光轮廓。镜头以60fps慢动作捕捉她们打闹的瞬间，发丝在空中飘扬，皮肤呈现瓷器般的光泽。房间布置精致奢华，香薰蜡烛、 designer 抱枕、水晶台灯等道具一闪而过。整体色调偏暖金，高对比度，人物轮廓光明显，呈现偶像剧级别的精致美感。

视觉风格:
- 画面质感: 4K超清，轻微柔焦，高级商业广告感
- 色彩风格: 暖金主调，高饱和，橙青分离调色
- 运镜方式: 升格慢动作+环绕+大量特写
- 特效元素: 逆光光晕、镜头光斑、皮肤柔焦美颜

声音设计:
- 配乐: 华丽弦乐+钢琴，戏剧感强
- 音效: 慢动作下的笑声回响

负面提示: 暗调、自然光、生活化、素颜、凌乱背景
```

### 2. 岩井俊二《情书》日系清新风格

**特点**：柔和自然光、低对比度、胶片颗粒、慵懒治愈

```
时长: 10秒
风格: 岩井俊二日系清新

提示词:
慵懒的周末清晨，两束柔和的阳光穿过白色纱帘，在陈旧的木地板上投下淡黄色的光斑。两个女孩穿着简单的棉质睡衣——淡蓝色的吊带背心配短裤、米白色的宽松T恤——坐在有些磨损的地毯上轻声嬉笑。她们的动作不紧不慢，像是刚睡醒的样子，头发自然地散落在肩上。镜头以手持的方式近距离观察她们，偶尔轻微失焦又重新对焦。房间里堆着书本、 CDs、还有一张老旧的书桌。整体画面像是被时光漂洗过，带着淡淡的怀旧感。

视觉风格:
- 画面质感: 16mm/35mm胶片感，明显颗粒，柔和的色彩
- 色彩风格: 低饱和，淡青+暖黄，日系胶片调色
- 运镜方式: 手持跟拍，呼吸感晃动，自然不做作
- 特效元素: 柔焦、胶片颗粒、轻微过曝的高光

声音设计:
- 配乐: 小林武史风格钢琴，极简治愈
- 音效: 窗外的风声、远处的车声、轻柔的笑声

负面提示: 高饱和、锐利画面、精致布置、浓妆、戏剧光效
```

### 3. 陈可辛《那些年》台湾青春片风格

**特点**：阳光灿烂、怀旧色调、自然青春、回忆感

```
时长: 10秒
风格: 台湾青春校园怀旧

提示词:
2000年代初的大学女生宿舍，阳光从老旧的铝合金窗框斜射进来，在地上画出斜长的光影。两个女孩穿着那个年代常见的睡衣——碎花棉睡裙、印着卡通图案的大T恤——正蹲在地上翻看一本漫画书，时不时笑作一团。她们的头发随意地扎着，脸上带着刚睡醒的红晕。房间里堆满那个年代的物品：台式电脑、磁带、贴满海报的墙壁、晾着的衣服。镜头用暖黄色的怀旧滤镜，偶尔加入胶片闪帧效果，像是翻开一本老相册。

视觉风格:
- 画面质感: 2000年代DV感+胶片颗粒，略带褪色
- 色彩风格: 暖黄怀旧调，略低的饱和度
- 运镜方式: 模拟手持DV，偶尔变焦推拉，有年代感
- 特效元素: 胶片闪帧、轻微划痕、褪色效果

声音设计:
- 配乐: 九把刀风格青春吉他，回忆感强
- 音效: 老式电风扇嗡嗡声、翻书声、2000年代流行歌从收音机传出

负面提示: 现代感、精致装修、高清锐利、时尚元素
```

### 4. Netflix《性爱自修室》欧美青春剧风格

**特点**：大胆配色、英式幽默感、明快节奏、生活化

```
时长: 10秒
风格: 欧美青春喜剧

提示词:
明亮的英式学生宿舍里，两个女孩穿着有趣图案的睡衣——一件印着「NOT A MORNING PERSON」，另一件是亮黄色的短款T恤——正在进行一场激烈的枕头大战。阳光从大窗户照进来，整个房间充满活力。她们的动作夸张而搞笑，枕头击中的瞬间羽毛飞溅，一个女孩假装戏剧性地倒下，另一个大笑不止。房间布置充满个性：墙上贴着乐队海报、书架上摆着唱片、地上散落着零食包装。镜头以快节奏剪辑捕捉最搞笑的瞬间，色彩鲜艳明快。

视觉风格:
- 画面质感: 数字高清，锐利，现代感强
- 色彩风格: 大胆鲜艳，高饱和，英式复古配色
- 运镜方式: 快节奏剪辑+手持+大量反应镜头
- 特效元素: 夸张表情特写、羽毛慢动作

声音设计:
- 配乐: 英式独立流行，欢快节奏
- 音效: 夸张的枕头击打声、戏剧性笑声、英式口音玩笑对话

负面提示: 慢镜头、文艺感、暗调、严肃氛围
```

### 5. 王家卫《花样年华》文艺慢调风格

**特点**：慢镜头、浓烈色彩、情绪化、诗意独白

```
时长: 10秒
风格: 王家卫文艺美学

提示词:
（画外音独白）「有时候，最美好的时光，就是这样无意义地虚度......」

缓慢的镜头里，阳光以不真实的角度穿透半透明的窗帘，在墙上形成一道道金色的条纹。两个女孩穿着复古质感的丝绸睡衣——墨绿色吊带、酒红色丝袍——她们的每一个动作都像是被刻意放慢。一个女孩伸出手，轻轻推了一下另一个的肩膀，对方的头发在慢镜头中缓缓飘起。她们的笑容带着一丝恍惚，仿佛沉浸在自己的世界里。房间里的物件被阳光勾勒出清晰的轮廓——梳妆台上的香水、镜子里模糊的倒影、飘动的窗帘。

视觉风格:
- 画面质感: 浓郁胶片感，高对比，强烈的明暗分离
- 色彩风格: 浓烈的红/绿/金色，强烈的主色调
- 运镜方式: 大量慢动作，固定镜头+缓慢推轨
- 特效元素: 时间流逝感、抽帧效果、情绪化光影

声音设计:
- 配乐: 纳京高爵士乐或大提琴独奏
- 音效: 缓慢的呼吸声、衣料摩擦声、远处的钟声
- 旁白: 可选：文艺独白（如上）

负面提示: 明快节奏、自然光、生活化、现代感
```

## 动作场面风格示例

### 基础提示词

> **一个黑衣女侠大战锦衣卫**

### 1. 昆汀暴力美学风格

**效果呈现**：血浆喷的到处都是

```
时长: 10秒
风格: 昆汀·塔伦蒂诺暴力美学

提示词:
黑衣女侠手持双刀，在雨夜的小巷中与五名锦衣卫展开血腥对决。镜头以经典的低角度仰拍，展现女侠的冷酷神情。每一次挥刀都伴随着夸张的血液喷溅效果——鲜红的液体在空中形成弧形的血雾，溅在镜头上。女侠的动作干脆利落，像是舞蹈一般优雅而致命。锦衣卫们一个个倒下，伤口喷出的血液在雨水冲刷下形成红色的溪流。画面偶尔切换到慢动作特写，捕捉血液飞溅的唯美瞬间。

视觉风格:
- 画面质感: 高对比度胶片感，明显的颗粒
- 色彩风格: 黑白主调+鲜红强调色（类似《杀死比尔》）
- 运镜方式: 低角度仰拍+360度环绕+大量特写
- 特效元素: 夸张的血液喷溅、雨滴慢动作、镜头血迹

声音设计:
- 配乐: 暴力美学风格的复古配乐
- 音效: 刀剑碰撞声、夸张的血液喷溅声、雨声

负面提示: 干净画面、现代装束、含蓄的打斗
```

### 2. 张艺谋中式水墨风格

**效果呈现**：人物有点假需要优化，但美学拉满

```
时长: 10秒
风格: 张艺谋中式水墨美学

提示词:
在水墨渲染般的竹林间，黑衣女侠与锦衣卫的对决如同一场写意的舞蹈。镜头以极慢的速度捕捉女侠腾空而起的瞬间，她的衣袂在风中飘动，如同水墨画中的笔触。锦衣卫的攻击被转化为抽象的线条，女侠的闪避则如行云流水。画面中大量使用留白，远处山峦以淡墨勾勒，近处竹叶随风飘落。整个打斗过程如同一幅会动的水墨画，动作优雅到近乎不真实。

视觉风格:
- 画面质感: 水墨质感，低对比度，大量留白
- 色彩风格: 黑白灰主调，偶尔点缀淡彩（红/青）
- 运镜方式: 极慢的升格镜头+大量留白构图
- 特效元素: 水墨晕染效果、飘落的竹叶、抽象化的动作

声音设计:
- 配乐: 古琴+箫，极简空灵
- 音效: 风声、竹叶沙沙声、极简的刀剑声

负面提示: 写实风格、鲜艳色彩、复杂背景
```

### 3. 邵氏老电影风格

**效果呈现**：运镜推拉很到位，演员表演的做作感也很到位，血浆的假也很到位

```
时长: 10秒
风格: 70年代邵氏武侠片

提示词:
在明显是摄影棚搭建的"古街道"布景中，黑衣女侠与锦衣卫展开对决。镜头以标志性的快速推拉变焦，在女侠的特写和全景之间快速切换。演员们的表演带着那个年代特有的舞台感——表情夸张、动作程式化。当刀剑"击中"目标时，喷出的是明显是红色颜料的"血液"，效果假得可爱。女侠的每一招都伴随着夸张的音效和戏剧性的pose。背景里甚至可以看到微微晃动的假树。

视觉风格:
- 画面质感: 70年代胶片感，明显的颗粒和褪色
- 色彩风格: 偏黄的怀旧色调，略带红色偏移
- 运镜方式: 快速推拉变焦+固定机位+戏剧化构图
- 特效元素: 明显假的血浆、舞台化打斗、布景感背景

声音设计:
- 配乐: 传统京剧风格的武打配乐
- 音效: 夸张的刀剑声、戏剧性的打击音效、"打斗"配音

负面提示: 现代感、写实打斗、精致特效
```

## 专家级提示词公式

```
完美提示词 = 具体主体 + 清晰动作 + 精准场景 + 明确风格 + 技术参数
```

### 常见错误 vs 正确示范

| 错误 | 正确 |
