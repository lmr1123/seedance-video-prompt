## 一、视听语言基础

> 景别和运镜的完整关键词速查请查阅 [style-keywords.md](style-keywords.md) 第四节和 [camera-movement.md](camera-movement.md)。
> 本节从影视理论角度解释景别的**叙事原理**。

### 1.1 景别运用原则

- **由远及近**：建立空间→进入故事→感受情绪
- **由近及远**：情绪爆发→揭示真相→开放结局
- **跳切同景别**：强调对比、时间流逝、情绪累积

## 二、蒙太奇理论

### 2.1 蒙太奇类型

| 类型 | 定义 | 效果 | AI提示词示例 |
|------|------|------|-------------|
| **叙事蒙太奇** | 按时间/逻辑顺序组接 | 讲述故事、推进情节 | "按时间顺序组接，展示人物一天的生活" |
| **平行蒙太奇** | 两条线索交替剪辑 | 制造悬念、对比 | "双线叙事，A和B同时进行，交替切换" |
| **交叉蒙太奇** | 多条线索汇合 | 高潮、紧张感 | "三线交叉，最后汇聚到同一时刻" |
| **心理蒙太奇** | 展现内心世界 | 梦境、回忆、幻想 | "闪回镜头，碎片化回忆，梦幻色调" |
| **隐喻蒙太奇** | 画面产生象征意义 | 深层含义、艺术表达 | "枯叶飘落隐喻生命消逝" |

### 2.2 经典蒙太奇手法

```
【快速剪辑】
- 每个镜头0.5-2秒
- 制造紧张、兴奋、混乱感
- 提示词："快切，每个镜头1秒，节奏紧凑"

【慢镜头】
- 放慢动作，延长时间感
- 强调关键时刻、情感爆发
- 提示词："慢动作，120fps升格拍摄效果"

【时间压缩】
- 长时间事件浓缩为短镜头组
- 展示过程、变化
- 提示词："时间流逝蒙太奇，日落月升，四季变换"
```

## 三、叙事结构

### 3.1 三幕式结构

```
第一幕：建立（约25%）
├── 介绍主角和世界观
├── 触发事件（打破平衡）
└── 第一幕高潮（进入新世界）

第二幕：对抗（约50%）
├── 试炼与盟友
├── 中点（重大转折）
└── 一切尽失（低谷）

第三幕：解决（约25%）
├── 最终决战
└── 新的平衡
```

### 3.2 短视频叙事结构（15秒版）

```
【黄金5秒】
0-3秒：钩子（Hook）- 最精彩的画面先上
3-5秒：建立情境 - 观众知道在发生什么

【核心内容】
5-12秒：展开故事/展示核心内容

【收尾】
12-15秒：反转/高潮/悬念/行动号召
```

### 3.3 叙事视角

| 视角 | 特点 | 效果 | 提示词示例 |
|------|------|------|-----------|
| **第一人称** | 主观视角 | 代入感强、沉浸式 | "第一人称主观视角，手持摄影感" |
| **第三人称** | 客观观察 | 叙事清晰、全知视角 | "第三人称客观视角，稳定构图" |
| **上帝视角** | 俯瞰全局 | 宏大、命运感 | "俯拍镜头，上帝视角，展示全局" |

## 四、声音设计

> 声音设计的完整指南请查阅 [sound-design-guide.md](sound-design-guide.md)。
> 本节仅从影视理论角度解释声画关系的**叙事原理**。

### 4.1 声画关系的三种模式

- **声画同步**：画面与声音情绪一致（最常见、最安全）
- **声画对位**：画面与声音情绪相反，产生讽刺/复杂情感（高级技巧）
- **声画分立**：声音独立于画面，扩展叙事空间（如画外音讲述过去，画面展示现在）

## 五、色彩理论

### 5.1 色彩情绪

| 色彩 | 情绪联想 | 适用场景 | 提示词示例 |
|------|---------|---------|-----------|
| **红色** | 热情、危险、爱情 | 激情戏、警示 | "红色主调，热烈奔放，高饱和" |
| **蓝色** | 冷静、忧郁、科技 | 科幻、悲伤 | "冷蓝色调，科技感，忧郁氛围" |
| **黄色** | 温暖、希望、警示 | 治愈、怀旧 | "暖黄调，复古胶片感，温馨" |
| **绿色** | 自然、嫉妒、不安 | 森林、悬疑 | "绿色调，诡谲氛围，不安全感" |
| **紫色** | 神秘、高贵、梦幻 | 奇幻、贵族 | "紫色调，神秘梦幻，霓虹感" |
| **黑白** | 怀旧、艺术、严肃 | 艺术片、回忆 | "黑白画面，高对比度，经典质感" |

### 5.2 经典色彩方案

```
【互补色】
- 对比强烈，视觉冲击
- 常见：橙/蓝、紫/黄
- 提示词："橙青配色，好莱坞大片风格"

【类似色】
- 和谐统一，舒适感
- 同色系渐变
- 提示词："蓝色系渐变，冷静统一"

【三等分色】
- 丰富但不混乱
- 适用于复杂场景
- 提示词："三色配色，丰富和谐"
```

## 六、导演风格与流派

> 导演风格关键词速查和完整的风格组合请查阅 [style-keywords.md](style-keywords.md) 和 [style-combinations.md](style-combinations.md)。
> 本节仅从影视理论角度解释导演风格的**视觉原理**，帮助理解"为什么"。

### 6.1 导演风格的视觉原理

- **王家卫** — 用慢快门拖影和抽帧效果制造"时间的黏稠感"，霓虹灯光不只是背景装饰，而是情绪的外化。本质是用视觉手段让观众"感受"到角色内心的孤独和暧昧。
- **韦斯·安德森** — 对称构图和糖果色的本质是"控制感"，一切井然有序的画面传递出童话般的非真实感，让观众进入一个被精心设计的平行世界。
- **诺兰** — IMAX画幅和实景感的本质是"物理真实"，即使在最离奇的科幻设定中，画面的质感也让观众相信这是真实发生的。
- **昆汀** — 长镜头和对白的本质是"紧张感的积累"，暴力不是目的，暴力前那段漫长的等待才是。
- **维伦纽瓦** — 大尺度极简的本质是"压迫感"，画面中的空旷不是美，而是让人物在宇宙面前显得渺小。

### 6.2 电影流派的视觉逻辑

- **黑色电影**：高对比光影 = 道德的模糊地带。明暗分界越锐利，善恶的界限越不清晰。
- **法国新浪潮**：手持摄影+跳切 = 打破"电影要好看"的规则。粗粝感就是真实感。
- **赛博朋克**：霓虹+雨天 = 高科技低生活的视觉翻译。光鲜的技术和肮脏的街道共存。
- **魔幻现实主义**：超现实元素+平静日常 = 让不可思议变得理所当然。

## 七、剪辑节奏与节拍

### 7.1 节奏控制

```
【快节奏】
- 镜头时长短（0.5-2秒）
- 动作紧凑、信息密集
- 适用：动作戏、音乐卡点、广告
- 提示词："快节奏剪辑，平均镜头1秒，动感十足"

【慢节奏】
- 镜头时长长（5秒+）
- 情绪延展、沉浸感
- 适用：艺术片、情感戏、风光
- 提示词："缓慢节奏，长镜头，情绪沉浸，呼吸感"

【节奏变化】
- 快→慢：情绪沉淀、高潮后平静
- 慢→快：危机升级、紧张感爆发
- 提示词："先慢后快，从平静到紧张，节奏递进"
```

### 7.2 音乐卡点剪辑

```
【基础卡点】
- 切镜点对准节拍点
- 动作幅度与音乐强度同步
- 提示词："镜头切换卡在音乐节拍上，动作与节奏同步"

【进阶卡点】
- 重音点：大动作/特效
- 弱音点：小过渡/微表情
- 静音点：定格/黑屏
- 提示词："音乐高潮时大动作爆发，静音处画面定格"
```

## 八、AI时代的影视理论应用

### 8.1 Seedance 2.0 核心能力与理论对应

| 影视理论 | Seedance 2.0 实现 | 提示词技巧 |
|---------|------------------|-----------|
| 景别控制 | 直接描述景别 | "中景镜头，腰部以上构图" |
| 蒙太奇 | 分镜描述+时间标注 | "[00:00-00:05] 镜头1：..." |
| 声音设计 | 音效/配乐描述 | "背景音：雨声+钢琴曲" |
| 色彩理论 | 色调/风格描述 | "王家卫风格，黄绿色调" |
| 运镜控制 | 镜头运动描述 | "镜头缓慢推进，从全景到近景" |

### 8.2 AI视频创作公式

```
【基础公式】
景别 + 主体 + 动作 + 环境 + 光影 + 情绪 + 时长

示例：
"中景（景别），一位穿着黑色风衣的男人（主体），
缓缓转身回头（动作），雨夜街头（环境），
霓虹灯光打在脸上（光影），眼神复杂（情绪），10秒（时长）"

【进阶公式】
[时间段] 镜头编号：景别 + 运镜 + 主体动作 + 环境变化 + 声音提示

示例：
"[00:00-00:05] 镜头1：全景，缓慢推进，
女主站在悬崖边，风吹动裙摆，
海浪声+悲伤钢琴曲"
```
