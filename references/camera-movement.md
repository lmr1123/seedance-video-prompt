## 六、运镜禁忌与注意事项

### 避免的运镜
| 禁忌 | 问题描述 | 正确做法 |
|------|---------|---------|
| **越轴** | 跨越180度线造成空间混乱 | 保持轴线一侧拍摄 |
| **无意义移动** | 镜头移动没有目的 | 每次移动都要有叙事意义 |
| **过度摇晃** | 手持抖动过大影响观看 | 控制手持幅度或使用稳定器 |
| **频繁变焦** | 变焦过多显得业余 | 固定焦距或少量变焦 |

### Seedance 2.0 运镜注意事项
- **时长限制**：4-15秒内完成运镜描述
- **一次只描述1-2种运镜**：避免过于复杂
- **明确起止状态**：说明从什么景别到什么景别
- **与动作配合**：运镜要配合主体动作

## 快速参考卡片

### 常用运镜速查
```
推镜头 → 强调/紧张/聚焦
拉镜头 → 释放/揭示/结尾
摇镜头 → 展示/对比/发现
跟拍 → 代入/伴随/追踪
环绕 → 戏剧/展示/浪漫
升降 → 宏大/仪式/过渡
手持 → 纪实/紧张/真实
希区柯克 → 眩晕/震惊/不安
```

### 景别变化速查
```
远景 → 全景 → 中景 → 近景 → 特写  （推进叙事）
特写 → 近景 → 中景 → 全景 → 远景  （揭示环境）
远景 → 特写  （跳跃强调）
特写 → 远景  （情绪释放）
```
