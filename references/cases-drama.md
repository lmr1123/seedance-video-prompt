## AI漫剧案例

### 仙侠/奇幻类

**案例1：红金女皇→冰王变身**
```
首尾帧变身，15秒红金女皇→冰王变身镜头，暖冷色调剧烈反差，
0-3秒：慢推镜头聚焦红装女皇端坐鎏金王座，指尖轻摇鎏金折扇，衣料摩擦发出细碎声响，眼神冷冽扫视下方，背景宫灯暖光摇曳，伴随低沉的宫廷弦乐；
4-8秒：画面以女皇手中折扇为核心骤然迸射冰晶纹路，冰纹如蛛网般快速蔓延覆盖她的红袍、王座乃至整座宫殿，环绕摇镜快切特写她的面部泛红龟裂、发丝凝结冰碴的痛苦形变，伴随冰晶炸裂的脆响与低温嘶鸣，女皇低吟"这冰蚀之力……竟已入骨"；
9-12秒：仰拍拉远镜头定格变身完成的冰王端坐冰封王座，冰棱覆盖的骨节紧握冰扇，王座边缘冰锥滴落水珠，背景冰柱悬挂的冰凌微微晃动，伴随冰裂声与呼啸寒风；
12-15秒：缓推特写冰王猩红眼眸，他低吼开口"从此，世间再无女帝，只有冰夷之主"，最后镜头定格在冰王座的对称剪影，音效收束为冰火能量碰撞的嗡鸣并逐渐消散。
```

**案例2：仙侠天界朝圣**
```
15秒仙侠天界朝圣风镜头，暖金色调，
0-3秒：低角度跟拍身着蓝袍的主角沿玉阶缓步前行，衣摆随山风轻拂飘动，两侧云雾缓慢翻涌流动，远处多层鎏金拱门层层递进延伸，背景轻柔仙乐缓缓响起；
4-8秒：镜头缓缓推近，主角踏上玉阶顶端，抬手拂过身侧拱门的龙纹浮雕，浮雕瞬间亮起淡金色符文，伴随细微的符文嗡鸣音效；
9-12秒：仰拍拉远，主角驻足于最内层拱门前，拱门顶端的仙宫金瓦在日光折射下迸发细碎金光，云雾从拱门缝隙中翻涌而出，仙乐音量略微提升；
13-15秒：缓推特写主角侧脸，他眼神凝注前方仙宫，低声开口"今日，我便要入这凌霄殿，问清当年之事"，最后镜头定格在拱门正中的仙宫剪影，仙乐渐弱，只余云雾流动的轻响。
```

**案例3：暗黑魔法爆发**
```
15秒暗黑魔法爆发镜头，紫黑冷色调，
0-3秒：低角度仰拍悬浮于星空中的魔法主角，双手凝聚跳动的紫色火焰，衣袍被能量气流吹得猎猎飘动，头顶巨型魔法阵缓慢旋转发光，背景陨石缓缓漂浮，伴随魔法阵嗡鸣与低沉咒语声，主角咬牙低吼"以我之血，引星穹之力！"；
4-8秒：环绕摇镜快切特写，主角掌心火焰暴涨浮现金色符文，脚下与头顶的双法阵形成紫色能量对流，电光在符文间穿梭，周边陨石被能量波震得碎裂，伴随能量流动嘶鸣与陨石崩裂声；
9-12秒：仰拍拉远定格慢放，主角双臂高举，双掌火焰汇聚成巨型紫色能量球，能量球撕裂星空，法阵符文全部亮起，背景残垣建筑在冲击下震颤，伴随能量凝聚的轰鸣与空气扭曲声；
13-15秒：缓推特写主角赤红眼眸，他嘶吼"湮灭！"，能量球瞬间爆发成紫色冲击波扩散，镜头随冲击波扫过破碎星空，最后定格在法阵残纹，音效收束为冲击波余响与渐弱风声。
```

**案例4：中国奇幻动画史诗**
```
这部作品采用中国奇幻动画电影风格，营造出史诗般的黑暗奇幻氛围，并运用了超精细的CG动画技术。故事发生在一座古老神秘的寺庙内，浓密的紫色立体迷雾笼罩着大地。雕刻精美的石柱和金色的龙形浮雕静静伫立，而一个巨大的紫色能量漩涡在上方缓缓旋转。镜头以缓慢的电影式推进，略微向上倾斜，漩涡中迸发出耀眼的光芒，紫色的粒子在空中飘荡。

一位身着飘逸古袍的沉稳男性主角从迷雾中缓缓走来。中景镜头过渡到中近景，长袍的布料和长发在能量之风中轻轻飘动。他神情冷峻沉稳，目光直视前方，手中轻握着武器。在他身后，紫色的阴影生物逐渐从迷雾中浮现，它们闪烁的双眼愈发耀眼，迷雾也愈发浓重。镜头的微妙移动更增添了紧张感。

随着压力骤增，一股强大的力量从主角体内爆发而出，紫色光环迅速向外扩散，能量粒子加速运动，镜头微微晃动，光芒骤然闪耀，他的头发和长袍猛然扬起，双眼开始发光，他缓缓抬起头，用低沉而克制的声音说道："你们……不配。"

能量漩涡扩张至充满整个画面，时间短暂地慢了下来，暗影生物的动作瞬间凝固，紫色的光芒笼罩了整个场景，镜头戏剧性地特写主角的脸部，紧张感达到顶峰，画面淡出至白色，电影般的结尾，扣人心弦的悬念，高对比度的光影效果，强烈的景深，专业的动画风格动作，适合制作15秒AI动画短片。
```

## 真人感短剧案例

### 虐心/情感爆发类

**案例5：志愿者与张奶奶**
```
画面（0-5秒）：特写张奶奶通红的眼眶，手指死死指着志愿者，眼泪砸在衣襟上，情绪濒临崩溃
台词1（张奶奶，哽咽怒吼）：你到底想骗我什么？利用老陈有意思吗！

画面（6-10秒）：志愿者双手紧握录音笔，浑身微颤，红着眼眶往前递，镜头扫过,展示床头的裂纹
台词2（志愿者，急切哽咽）：我没有骗您！这是陈爷爷生前托付我的，是他要陪您啊！

画面（11-15秒）：志愿者猛地按下录音笔，陈爷爷低沉的声音初响，张奶奶瞬间僵住，眼神从愤怒转为震惊，双手微微抬起

音效：急促钢琴音+手机电流杂音，张奶奶哽咽声，录音笔按键声，结尾混入陈爷爷模糊人声
时长：精准15秒（每帧紧凑，无冗余）
```

### 搞笑/脑洞类

**案例6：前男友变柴犬**
```
画面（0-5秒）：特写女生拽着柴犬（前男友）的项圈，柴犬疯狂挣扎、龇牙（眼神透着人形的慌张），女生面无表情，另一只手拎着宠物医院绝育告知单
台词1（女生，语气拽且解气）：以前渣我的时候不是挺横？今天就送你"断情绝爱"！

画面（6-10秒）：女生用力把柴犬往宠物医院门口拽，柴犬四肢蹬地、呜咽（像人求饶），镜头扫过医院"绝育专区"牌子，女生嘴角勾起坏笑
台词2（女生，调侃）：别挣扎了，做完绝育，你就再也不能到处撩骚啦～

画面（11-15秒）：女生强行把柴犬抱起来往里面冲，柴犬脑袋乱晃、爪子乱扒（眼神绝望），镜头定格两人反差脸上
音效：轻快搞笑的背景音，柴犬挣扎呜咽声，女生调侃的笑声
时长：精准15秒（节奏轻快，脑洞感拉满）
```

### 短剧经典类（霸总/甜宠/爽剧）

**案例7：失忆霸总**
```
画面（0-5秒）：特写两人拉扯镜头，女主拽着总裁领带，距离极近，总裁眼神迷茫（失忆状态），皱眉呵斥，女主嘴角挂着不屑笑意
台词1（总裁，迷茫又强势）：女人，你敢放肆？我告诉你，我只认我的白月光！

画面（6-10秒）：女主猛地用力拽紧领带，总裁俯身贴近，女主指尖戳他胸口，镜头扫过桌上总裁和女主的旧合照（伏笔），女主眼神变冷
台词2（女主，拽酷反杀）：白月光？总裁，你失忆前，可是跪着求我别离开！

画面（11-15秒）：女主松开领带，总裁踉跄一下，眼神从迷茫转为震惊，女主转身挑眉回望，嘴角勾起挑衅笑意，镜头定格两人反差神情
音效：低沉有张力的背景音，领带拉扯声，总裁低沉呵斥声，女主清冷笑声
时长：精准15秒（狗血感、拉扯感拉满）
画面全部片段都不要出现字幕，并且最后添加声音说"预知后事如何，请看下集"
```
