# Seedance 2.0 声音设计指南

Seedance 2.0 在声音方面有显著提升："音色更准，声音更真"。本文档帮助你在提示词中充分利用声音能力。

---

## 一、声音类型与描写方式

### 1. 对白（Dialog）

**功能**：角色说话，支持口型同步
**描写要点**：
- 明确说话者身份
- 标注情绪和语气
- 写出完整台词内容
- 可指定语言/方言

```
【标准格式】
台词（角色名，语气描述）："具体台词内容"

【示例】
台词（女主，哽咽怒吼）："你到底想骗我什么？"
台词（男主，急切低语）："你听我解释！"
台词（旁白，深沉男声）："那一天，一切都变了。"
```

**方言/多语言支持**：
```
- 四川话："幺妹儿，这个好安逸嘛！"
- 粤语："你食咗饭未啊？"
- 韩语："새해 복 많이 받으세요!"
- 西班牙语："¡Vamos!"
- 科普风配音："用科普风格和音色讲解..."
```

### 2. 旁白（Narration）

**功能**：画外叙事，不需要角色出现
**描写要点**：
- 标注音色特征（深沉/温柔/童声）
- 标注语速和情感
- 旁白内容用引号标注

```
【示例】
旁白（低沉磁性男声，缓慢讲述）："在这座城市的角落里，有一个不为人知的故事。"
旁白（温柔女声）："新年快乐，愿你所愿皆如愿。"
```

### 3. 音效（Sound Effects）

**功能**：增强真实感和沉浸感
**描写方式**：直接描述想要的声音

```
【环境音效】
- 自然环境：风声、雨声、雷声、鸟鸣、海浪、流水
- 城市环境：车流声、喧嚣声、脚步声、门铃声
- 室内环境：钟表滴答、空调嗡鸣、键盘敲击

【动作音效】
- 人物动作：脚步声、呼吸声、衣料摩擦声
- 物品交互：开门声、杯子碰撞声、纸张翻动
- 打斗/运动：拳击声、剑鸣声、碰撞声、爆炸声

【特殊音效】
- 科技感：电子嗡鸣、数据流声、全息投影音
- 魔法/特效：能量聚集声、粒子爆发声、符文激活声
- 转场音效：whoosh风切声、低频"砰"声、残响

【描写模板】
"脚步声由远及近 + 门吱呀打开 + 室内钟表滴答"
"剑刃出鞘声 + 金属碰撞 + 冲击波扩散嗡鸣"
```

### 4. 配乐（Background Music）

**功能**：自动生成配乐，可通过描述引导风格
**描写方式**：

```
【按情绪描述】
- "悲情钢琴曲，渐强至高潮"
- "轻快活泼的电子音乐"
- "紧张悬疑的弦乐"
- "温暖治愈的吉他弹唱"
- "史诗感交响乐，鼓点有力"

【按风格描述】
- "K-pop强节奏电子音乐，打击感十足"
- "中国古风音乐，古筝+笛子"
- "好莱坞大片级配乐"
- "日式清新BGM"
- "拉美民族风音乐"
- "科技感电子音乐，合成器为主"

【按节奏描述】
- "节奏从缓慢到急促"
- "音乐高潮与画面高潮同步"
- "卡点节奏，鼓点与切镜同步"
- "渐弱收尾，余音缭绕"
```

### 5. 音频参考（@音频引用）

**功能**：上传音频素材作为参考
**使用方式**：

```
"背景音乐参考 @音频1 的节奏和氛围"
"旁白音色参考 @视频1 中的男声"  （也可以参考视频中的声音）
"配乐风格参考 @音频1，但节奏更快"
```

## 二、声画关系设计

### 声画同步（最常用）
画面情绪与声音情绪一致
```
画面：温馨家庭团聚 → 配乐：温暖轻快
画面：紧张追逐场面 → 配乐：急促紧张 + 心跳声
画面：产品展示高潮 → 配乐：节奏高点 + 品牌音效
```

### 声画对位（制造反差）
画面与声音情绪相反，产生讽刺/复杂情感
```
画面：暴力打斗场面 → 配乐：轻快儿歌（黑色幽默）
画面：悲伤分离场景 → 配乐：欢快音乐（讽刺/回忆反差）
```

### 声画分立（扩展叙事）
声音独立于画面，增加信息层次
```
画面：展示现在 → 旁白：讲述过去
画面：安静的空间 → 画外音：角色内心独白
```

## 三、音乐卡点技巧

### 基础卡点
```
"镜头切换卡在音乐节拍上"
"动作幅度与音乐强度同步"
```

### 进阶卡点
```
"音乐重音点：大动作/特效爆发"
"音乐弱音点：微表情/小过渡"
"音乐静音点：画面定格/黑屏"
"鼓点收尾：最后一声踩点定格"
```

### 卡点提示词模板
```
"@图片1-@图片7 的画面根据 @视频1 中的音乐关键帧位置和整体节奏进行卡点，
画面中的人物更有动感，可根据音乐及画面需求自行改变参考图的景别，
及补充画面的光影变化"
```

## 四、场景声音设计速查

| 场景类型 | 推荐配乐 | 推荐音效 | 声画关系 |
|---------|---------|---------|---------|
| 情感短剧 | 钢琴曲/弦乐 | 雨声、叹息、心跳 | 同步 |
| 产品广告 | 科技电子/品牌调性 | 产品交互声、品牌音效 | 同步+收尾定格 |
| 特效大片 | 史诗交响乐 | 爆炸、剑鸣、能量波 | 同步+高潮卡点 |
| 舞蹈MV | 强节奏电子/Hip-hop | 舞步声、呼吸、衣料声 | 严格卡点 |
| 美食展示 | 轻松治愈BGM | 煎炒声、切菜声、咀嚼声 | 同步 |
| 科普教学 | 清晰平稳BGM | 数据音效、环境音 | 分立（旁白讲解） |
| 恐怖/悬疑 | 低频嗡鸣/不和谐弦乐 | 门吱呀、脚步、呼吸 | 对位（安静中的突然音效） |
| Vlog/日常 | 清新轻快/独立民谣 | 环境音、生活声 | 同步 |

## 五、声音描写模板

### 完整声音设计块
```
声音设计:
- 配乐风格: [具体描述]
- 环境音效: [场景相关音效]
- 动作音效: [与主体动作配合的音效]
- 对白/旁白: [如有，写出具体内容和音色要求]
- 音乐节奏: [与画面节奏的关系]
```

### 简化声音提示
```
"背景音：轻柔钢琴曲渐强，结尾处有轻微的叹息声"
"音效：脚步声由远及近 + 门吱呀声 + 室内钟表滴答"
"配乐：科技感电子音乐，节奏明快，结尾处有品牌音效"
```
