## 使用建议

### 组合使用公式
```
[导演风格/流派] + [画面质感] + [色彩风格] + [情绪氛围] + [运镜方式]
```

**示例：**
```
"王家卫风格 + 胶片感 + 港风复古色调 + 暧昧忧郁氛围 + 手持跟拍"
"赛博朋克 + 霓虹灯光 + 冷调未来 + 神秘紧张 + 快速剪辑"
"日系小清新 + 柔焦梦幻 + 低对比暖调 + 治愈温馨 + 缓慢推镜头"
```

### 风格强度控制
- **轻度**：使用2-3个关键词
- **中度**：使用4-6个关键词
- **重度**：使用7+关键词 + 具体参数
