# Seedance 2.0 提示词常见失败模式与防错指南

本文档总结常见的提示词失败模式，帮助在生成提示词时主动规避问题。

---

## 一、硬性失败（直接导致生成失败或报错）

### 1. 上传写实人脸素材
**问题**：平台合规要求，暂不支持上传包含写实真人脸部的素材（图片和视频均不行）
**表现**：系统自动拦截，无法生成
**规避**：
- 使用 AI 生成的人物图片代替真人照片
- 使用动漫/3D/IP 形象代替写实人像
- 纯文字描述人物，不上传人脸素材

### 2. 超出文件数量/大小限制
**问题**：图片>9张、视频>3个、音频>3个、总文件>12个
**规避**：提醒用户精选最关键的素材，优先上传对画面或节奏影响最大的素材

### 3. 视频输入分辨率不符
**问题**：视频分辨率不在 480p-720p 范围内
**规避**：提醒用户调整视频分辨率后再上传

## 二、软性失败（生成成功但效果差）

### 4. 动作描述过度密集
**问题**：在 4-15 秒内塞入过多动作变化，模型无法全部完成
**反面示例**：
```
❌ "人物先跑步，然后跳起来翻滚，落地后转身拔刀，接着旋转挥剑，
最后收刀入鞘鞠躬" （15秒内5+连续动作）
```
**正确做法**：
```
✅ 15秒视频：每个镜头至少3秒，最多4-5个镜头
✅ 每个镜头内1-2个核心动作
✅ 复杂连续动作用分镜时间轴明确分配
```

### 5. 分镜时间分配不均
**问题**：前面时间段描述简单，后面时间段堆砌过多内容
**反面示例**：
```
❌ [00:00-00:08] 镜头1：人物站着
   [00:08-00:15] 镜头2：人物奔跑→跳跃→打斗→爆炸→慢动作定格→LOGO出现
```
**正确做法**：
```
✅ 每个分镜时间段内的内容复杂度应大致均衡
✅ 高潮段落可以稍长（4-5秒），但内容仍需精简
```

### 6. 运镜指令冲突
**问题**：同时描述相互矛盾的运镜方式
**反面示例**：
```
❌ "固定镜头，同时跟拍人物移动"
❌ "一镜到底，快速切换多个场景"
❌ "手持抖动感，画面极度稳定"
```
**正确做法**：
```
✅ 每个镜头段只指定1种主要运镜方式
✅ 如需切换运镜，在不同分镜段分别描述
✅ "一镜到底"意味着不切镜，场景转换靠运镜而非剪辑
```

### 7. 忽略物理合理性
**问题**：描述不符合物理规律的动作/场景
**反面示例**：
```
❌ "人物在水下正常说话对白"
❌ "人物从地面直接飞到太空，无过渡"
❌ "物体凭空消失又凭空出现"
```
**正确做法**：
```
✅ 如需超自然效果，明确标注"特效/魔法/超现实"
✅ 场景转换使用合理的过渡（转场/遮挡/光效）
✅ 动作遵循基本物理逻辑，除非刻意追求荒诞效果
```

### 8. 风格关键词过度堆砌
**问题**：使用7+风格关键词混搭，模型无法同时满足所有风格
**反面示例**：
```
❌ "王家卫风格 + 诺兰质感 + 昆汀暴力美学 + 韦斯安德森对称构图 + 
   赛博朋克 + 日系清新 + 水墨国风"
```
**正确做法**：
```
✅ 轻度风格化：2-3个关键词
✅ 中度风格化：4-5个关键词
✅ 重度风格化：5-6个关键词 + 具体参数
✅ 风格关键词之间应具有内在一致性
```

### 9. @引用指向不明
**问题**：上传多个素材但没有清楚说明每个素材的用途
**反面示例**：
```
❌ "参考上传的素材生成视频" （有5张图+2个视频，没说谁是谁）
```
**正确做法**：
```
✅ "@图片1 作为首帧画面"
✅ "@图片2 参考人物形象"
✅ "@视频1 参考运镜方式和转场效果"
✅ "@音频1 作为背景音乐"
✅ 每个 @引用 都明确标注用途
```

### 10. 提示词过于简单
**问题**：描述信息不足，模型自由发挥空间过大，结果不可控
**反面示例**：
```
❌ "一个人走路"
❌ "拍个广告"
❌ "好看的风景"
```
**正确做法**：
```
✅ 至少包含：主体 + 动作 + 场景 + 氛围
✅ 简单场景也需 50-100 字描述
✅ 明确时长、画面比例、核心情绪
```

## 三、优化技巧

### 提示词复杂度分级

| 场景复杂度 | 提示词长度 | 是否分镜 | 分镜数量 | 适用场景 |
|-----------|-----------|---------|---------|---------|
| 简单 | 50-100字 | 不需要 | - | 单主体+单动作+单场景 |
| 中等 | 100-250字 | 可选 | 2-3个 | 多动作+风格化+运镜 |
| 复杂 | 250-500字 | 建议 | 3-4个 | 多主体+场景切换+特效+对白 |
| 超复杂 | 400-600字 | 必须 | 4-5个 | 多模态+多角色+精确控制 |

### 15秒视频的黄金分镜节奏

```
【推荐结构】
[00:00-00:03] 开场钩子 — 最吸引人的画面/悬念
[00:03-00:07] 核心展开 — 主要内容/动作/情节
[00:07-00:11] 高潮/转折 — 最精彩的瞬间
[00:11-00:15] 收尾/定格 — 情感落点/品牌露出/悬念

【注意】
- 每个镜头最少 2-3 秒
- 15 秒最多 5 个镜头，建议 3-4 个
- 10 秒最多 3-4 个镜头，建议 2-3 个
- 5 秒最多 2 个镜头，建议 1-2 个
```

### 自检清单（生成提示词后过一遍）

- [ ] 是否超出平台参数限制？
- [ ] 是否包含写实人脸素材？
- [ ] 动作数量是否合理（每镜头1-2个）？
- [ ] 分镜时间分配是否均衡？
- [ ] 运镜指令是否有冲突？
- [ ] 风格关键词是否过多（>6个）？
- [ ] @引用是否都标明了用途？
- [ ] 描述是否足够具体（>50字）？
- [ ] 是否包含声音设计？
- [ ] 是否添加了负面提示？

## 四、生成不理想时的系统化排错流程

### 排查优先级（按顺序逐一检查）

当生成效果不理想时，不要盲目重写全部提示词。按以下优先级**逐一排查**，每次只调整一个维度：

| 排查顺序 | 检查维度 | 典型问题 | 修复方向 |
|---------|---------|---------|---------|
| **第1步** | 主体描述 | 模型没理解主体是谁/什么 | 增加具体外观、姿态、服装描述 |
| **第2步** | 动作/行为 | 动作没执行/执行错了 | 简化动作，每镜头只保留1个核心动作 |
| **第3步** | 运镜指令 | 镜头运动不对/冲突 | 每段只保留1种运镜，去掉矛盾指令 |
| **第4步** | 风格关键词 | 画面风格混乱/不是想要的 | 精简到2-3个核心风格词 |
| **第5步** | 分镜节奏 | 前松后紧/内容失衡 | 重新分配各段时间和内容密度 |
| **第6步** | 声音设计 | 声音不匹配/对白出错 | 简化声音描述，明确情绪和音色 |
| **第7步** | @素材引用 | 素材没被正确使用 | 检查每个@引用的用途说明是否清晰 |

### 具体问题快速修复表

| 问题现象 | 可能原因 | 快速修复方案 |
|---------|---------|------------|
| 整体画面模糊 | 未指定画质要求 | 加"4K超清""高画质""电影质感" |
| 人物变形/多余肢体 | 描述不够具体 | 加负面提示"不要变形""不要多余手指""面部清晰" |
| 动作断裂不连贯 | 动作太多太快 | 减少50%动作描述，加"动作连贯流畅" |
| 风格完全不对 | 风格词太多且矛盾 | 删到只剩2-3个一致的核心风格词 |
| 运镜很混乱 | 同时给了多种运镜 | 每段只用1种运镜，不同段可以不同 |
| @素材没有生效 | 引用格式错误/用途不明 | 确认"@图片1 作为[具体用途]"格式正确 |
| 场景切换突兀 | 缺少过渡描述 | 加转场说明（如"渐变过渡""镜头甩切"） |
| 节奏太快/太慢 | 分镜时间分配问题 | 调整各段时长比例 |
| 声音不搭配 | 声音描述模糊 | 明确配乐风格+具体音效+情绪关键词 |
| 对白口型不同步 | 对白太长/语言不明确 | 简化对白，明确标注语言和情绪 |

### 迭代优化的黄金原则

1. **单变量原则**：每次迭代只调整1个维度，观察效果后再决定下一步
2. **减法优先**：效果不好时先尝试删减，而非增加更多描述
3. **参考优先**：有参考素材（视频/图片）时效果通常优于纯文字描述
4. **核心先行**：先确保主体+动作正确，再调风格和细节
5. **平台特性**：Seedance 2.0 擅长动作复刻和运镜控制，充分利用@视频参考
