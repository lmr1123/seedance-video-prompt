专业的 Seedance 2.0 / 即梦 AI 视频提示词生成工具。这是一个深度结合了**严密影视逻辑**与**轻量级拟人交互**的智能体配置方案。无论是想快速验证灵感，还是追求殿堂级的精准导流，本项目都能助你生成结构化、高出片率的完美视频描述。

---

## ✨ 全新进化：V2 核心特性

### 🌓 双模式架构：Lite 与 Pro 自由切换
- **SKILL-Lite (轻量极速版)**：脱水精简的单文件架构，极低的 Token 消耗，适合 90% 的日常短剧、发圈素材生成。零门槛，秒回复。
- **SKILL-Pro (专业外挂版)**：搭载 7300+ 行庞大知识库。引入 **RAG (检索增强) 动态加载机制**，仅在用户需要深究王家卫风格、希区柯克运镜等极客需求时加载，拒绝上下文乱飞。

### ⏱️ 十大核心能力 & 时间轴分镜法
- **能力前置诊断**：AI 会在暗中判断用户需求（音乐踩点、一镜到底、角色复刻等 **10大能力**），从而制定最优策略。
- **Timestamp Storyboarding**：抛弃模糊的动作描述，强制应用“0-3秒、4-8秒”的时间轴控制逻辑，将 15 秒短视频的起承转合拿捏到极致！

### 💬 4步拟人化交互工作流
- **不再“机器霸屏直出”**：AI 在思考后会用简短的“一句话”向您确认方案与参数，**停顿等待您的授权**，然后再铺开代码级的提示词。体验感丝滑、情绪价值拉满。

### 🛡️ 强制兜底防翻车系统
- **动态平台红线规避**：文档内嵌拟人自检清单。主动拒绝使用真实人类照片作底图，自动加上 `无水印、无字幕、不变形` 兜底免责负面词，确保每一次全垒打！

## 📖 使用方法

### 1. 告诉我你的需求

**简单输入**：
- "帮我生成一个10秒的猫咪打盹视频"
- "做一个15秒的赛博朋克城市夜景"
- "胡金铨风格的客栈武打，竖屏10秒"

**详细输入**（可选）：
```
【视频主题】：猫咪在咖啡馆打盹
【视觉风格】：日系清新治愈
【时长】：10秒
【比例】：9:16
```

### 2. 我会自动处理

```
【本轮执行路径】
- 时长路由：单段生成
- 素材路由：无素材需生成图片
- 复杂度判断：简单
- 采用模板：模板A

【决策说明】
用户要求10秒≤15秒，单主体单动作故判断为简单，
无素材但主题为生活场景，输出简洁版提示词。
```

### 3. 获取完整提示词

我会输出可直接复制到即梦的：
- 完整提示词
- 声音设计方案
- 禁止项声明
- 如需素材：附带图片生成提示词

## 🛠️ AI 内部执行工作流（对用户透明）

```
【第 1 步：倾听与暗中诊断】
├── 匹配十大核心能力（一镜到底/卡点等）
├── 决定时长路由（<15秒单段 / >15秒拼接）
└── 素材判断（选用 极简版/时间轴分镜版/多模态版）

【第 2 步：拟人简短破冰与确认】
└── 用亲和的话术向用户确认方案，停顿等待“开始生成”的指令。

【第 3 步：深入构建与质量自检】
└── 运行防翻车检测，按秒数严格铺设 Timestamp Storyboarding。

【第 4 步：完美输出】
└── 交付精美、带时间轴的结构化视频提示词。
```

## 💡 常见示例

### 示例 1：简单场景

**输入**：
> 猫咪在咖啡馆打盹，8秒

**输出路径**：
```
- 时长路由：单段生成
- 素材路由：无素材
- 复杂度：简单
- 模板：模板A
```

### 示例 2：有素材参考

**输入**：
> 参考@图1的男人形象，在@图2的电梯中，完全参考@视频1的运镜

**输出路径**：
```
- 时长路由：单段生成
- 素材路由：有素材
- 复杂度：中等
- 模板：模板C
```

### 示例 3：电商产品广告（精准卡点展示）

**输入**：
> 帮我写一个15秒的高级香水电商广告，时间轴分镜控制，音乐踩点

**输出特性**：
- 采用 **模板B：时间轴分镜法（Timestamp Storyboarding）**
- **0-3秒**：特写香水瓶身，微距运镜。
- **4-8秒**：香水喷洒动作，水珠慢动作，节奏逐渐加快。
- **9-15秒**：模特吸气留白，极简高级感收尾定调。

### 示例 4：霸道总裁短剧（微短剧剧本转换）

**输入**：
> "总裁把甩出黑卡，三分讥笑七分凉薄。10秒，竖屏短剧质感"

**输出特性**：
- 默认加入防拦截机制（无真实写实人脸，推荐手绘或插画人设参考，或使用平台生图打底）。
- 强调推镜头面部光影，狗血反转的音乐设计，以及标准的 9:16 短剧画幅控制。

### 示例 5：4K 科幻医疗解剖（高精建模渲染）

**输入**：
> 5秒的未来医疗机器人动手术的内部解剖视觉，4K超精细，微距镜头。

**输出特性**：
- 严格引用 `4K超分辨率、Octane渲染、机械生物发光、极高信息密度` 风格。
- 采用极简直接但要求极高精度的 **模板A**，防翻车词中强调“无文字标识”。

### 示例 6：音乐 MV（动态卡点与多景别）

**输入**：
> 女主在大雨中热舞，15秒韩风MV，节奏感超强

**输出特性**：
- 激活核心能力：**音乐踩点同步** 以及 **一镜到底追踪镜头**。
- 时间轴分镜下不仅写出画面，还将精确提示"音乐节拍：Bass Drop"发生的秒数位置。
